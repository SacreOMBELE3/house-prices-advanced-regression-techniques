# Gold — données analytiques finales

Cette couche est destinée aux jeux de données et tables finaux préparés pour les analyses, les vues SQL Server et la consommation par Power BI.

## État

Aucune donnée Gold n'est encore produite. Le schéma final, les tables et les vues analytiques sont à préciser au cours de l'implémentation et à aligner avec les besoins du tableau de bord.

Pour les données brutes et préparées, voir les dossiers [Bronze](../bronze/README.md) et [Silver](../silver/README.md).
