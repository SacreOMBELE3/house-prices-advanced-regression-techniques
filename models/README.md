# Modèles de Machine Learning

Ce dossier est réservé au modèle sélectionné et à ses artefacts sérialisés après entraînement et évaluation. Aucun modèle n'est actuellement présent.

Le cahier des charges prévoit de comparer une baseline, des régressions linéaire, Ridge et Lasso, Random Forest, Gradient Boosting et, si disponible dans l'environnement, XGBoost.

Documenter avec chaque artefact le procédé de préparation associé, la version des données, les paramètres utiles et les résultats obtenus sur validation. Ne jamais présenter `test.csv` comme un jeu d'évaluation étiqueté.
