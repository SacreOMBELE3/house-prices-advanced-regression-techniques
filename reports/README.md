# Rapports

Ce dossier accueillera le rapport final présentant la démarche, les résultats, les limites et les conclusions du projet. Aucun rapport final n'est encore présent.

Le document final pourra synthétiser l'audit des données, les principaux résultats de l'analyse exploratoire, les comparaisons de modèles sur validation, les métriques et les livrables SQL et Power BI effectivement réalisés.
