# Power BI

Ce dossier accueillera le fichier de rapport Power BI (`.pbix`) et, si nécessaire, les éléments complémentaires du tableau de bord. Aucun rapport n'est encore présent.

Les pages envisagées par le cahier des charges sont :

1. Vue d'ensemble des prix et des propriétés.
2. Caractéristiques immobilières et relations avec les prix.
3. Facteurs associés aux prix et comparaisons par quartier.
4. Résultats de modélisation, métriques et importance des variables.

Les sources du rapport (SQL Server, tables Gold et résultats de modèles) seront précisées lorsque les données et le modèle seront disponibles.
