# SQL Server

Ce dossier accueillera les scripts SQL de création de base et de schémas, de chargement des données, de transformation et de création des vues analytiques destinées notamment à Power BI.

## Organisation visée

- **Bronze** : stockage des données sources importées.
- **Silver** : données contrôlées et préparées.
- **Gold** : tables et vues prêtes pour l'analyse.

Aucun script SQL ni schéma de base n'est encore présent. Les objets futurs devront être documentés et rester cohérents avec les jeux de données produits dans `data/`.
