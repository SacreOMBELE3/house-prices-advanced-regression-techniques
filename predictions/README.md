# Prédictions

Ce dossier accueillera le fichier CSV final de prédictions destiné à la soumission Kaggle. Aucun fichier de prédictions n'est encore généré.

Le fichier devra respecter la structure de `data/bronze/sample_submission.csv`, notamment les colonnes d'identifiant et `SalePrice`. Les prédictions sont produites pour `test.csv` après sélection du modèle et réentraînement sur les données d'entraînement. Le jeu de test ne sert pas au calcul des métriques.
